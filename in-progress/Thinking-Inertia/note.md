# Thinking Inertia 論文筆記

Oct 25, 2026 · @Johnny Wu

## 三十秒版本

要求 LLM「不要思考」(關掉思考模式,或叫它直接給答案)之後,它的回應真的只剩答案嗎?這篇論文把每個回應拆成答案前的文字 T 與最終答案 A,用三層指標量 T:T 是不是空的(ETR)、和題目有多相關(QRel.)、有沒有明確的推理步驟(EIR)。

結論是:就可見的回應文字而言,無論用參數或提示詞,都不能可靠地關掉推理。只關思考開關時,答案前出現明確推理的比例(六個模型合併)在是非題約 5%、選擇題約 46%、開放式幾乎 100%。開放式加上「不要推理」的指令後仍有 62%,而且準確度會下降。另外,只在提示裡加一句 "Think step by step",許多模型在是非題上就會重新出現可見的明確推理(GPT-5.4 是例外),所以開關不是決定推理是否出現的唯一因素。論文只量可見的回應,不對模型內部運算下結論。

## 怎麼讀與索引

主軸:判斷模型有沒有在「不思考」,要看回應的實際內容,不能看開關、標記或長度;這樣量之後,會發現關掉開關擋不住可見的推理。

論文:Dianqiao Lei、Kevin Qinghong Lin、Pan Lu、Philip Torr、James Zou,"Thinking Inertia: LLMs Keep Thinking When Told Not To",arXiv:2610.11765v1 \[cs.CL\],2026-10-08。

先讀三十秒版本;主線每一節回答一個問題,符號與切分方式查【概念 1】。

- 主線 1 問題:三個舊指標為什麼失效

- 主線 3 實驗:關掉開關擋不住可見推理

## 1 問題:三個舊指標為什麼失效

既有工作用開關、特殊標記、輸出長度判斷模型有沒有在思考,三者看的都不是回應內容,所以會誤判。

論文 Figure 2,caption:"Surface proxies fail to identify response-level no-thinking." 下表重製 Figure 2(b) 的失敗案例,題目是 If 3x + 1 = 10, what is x?

| 舊指標 | 判斷依據 | 失敗案例 |
| --- | --- | --- |
| 1. 提示端控制 | 開關設成 no-think,就當作沒思考 | 開關已關,輸出仍寫出「兩邊減 1,3x = 9,再除以 3」 |
| 2. 特殊標記 | 沒有 `<think>` 區塊,就當作沒思考 | 沒有標籤,正文仍寫出「3x = 9,所以 x = 3」 |
| 3. 輸出長度 | 輸出夠短,就當作沒思考 | 只有一行 3x = 9, so x = 3,但這一行本身就是一步推導 |

誤判也會反向發生:一句沒有任何題目內容的開場白(論文舉的例子是 "Let me think about this. The answer should be `<ans>`")會被表面指標算成有推理。

因此論文改為直接檢查答案前文字的內容(見主線 2)。

## 2 方法:拆成 (T, A),再用三層指標量 T

論文不看開關、標記或長度,改為把每個回應拆成答案前文字 T 與最終答案 A,再用由嚴到寬的三層指標檢查 T;拆法與符號見【概念 1】。

&#91;embedded content: Figure 3 上半部(重繪):Response-centric metrics for measuring no-thinking\]

上圖重繪論文 Figure 3 的上半部,caption:"Response-centric metrics for measuring no-thinking." 題目經介入 S(·) 送進模型 π,輸出被拆成 T 與 A;三層指標只作用在 T,準確度另外評估 A。介入有哪些,見本節最後的六種模式。

### 層 1:ETR(Empty-Thinking Rate)

ETR 是最嚴格的檢查,只問 T 是不是完全空的,也就是有多少比例的輸出乾淨地只給答案。

```latex
e_i = \mathbb{1}\{|T_i| = 0\}, \qquad \mathrm{ETR} = 100\% \times \frac{1}{N}\sum_{i=1}^{N} e_i
```

- i:第 i 個輸出
- T\_i:第 i 個輸出的答案前文字
- |T\_i| = 0:T 是空的,沒有任何實質文字
- 1{·}:括號內成立為 1,否則為 0
- e\_i:單一輸出的分數
- N:同一個模型、同一種介入、同一個 benchmark 下的輸出總數

白話:每個輸出各打 0 或 1,再取平均。

e\_i = 1 的條件比「T 是空的」多一層:A 必須可解析,而且整段輸出在允許的答案框之外沒有實質文字,包含 A 之後的文字。格式壞掉、或答案後面又接解釋的輸出,一樣得 0。

限制:T 一旦非空,ETR 就分不出空話、改寫與真正的推理,所以需要層 2 與層 3。數字例子見本節的六個案例。

### 層 2:QRel.(Question–Pre-answer Relevance)

QRel. 補上一個連續分數,量 T 和題目有多相關;它用相關性取代長度。

```latex
\mathrm{QRel.}(Q_i, T_i) = \begin{cases} 0, & |T_i| = 0 \\ \cos\big(\phi(Q_i),\ \phi(T_i)\big), & |T_i| > 0 \end{cases}
```

- φ:embedding 編碼器,論文用 Qwen3-Embedding-4B
- φ(Q\_i):題目加上查詢指令後的向量;指令是「給定一個問題,檢索包含回答此問題之推理的答案前文字」
- φ(T\_i):把 T 當候選段落編成的向量
- cos:兩個向量先各自除以自己的長度(ℓ2 正規化),再取內積,等於夾角的餘弦
- 第一行:T 是空的,直接給 0

白話:空的給 0,不空的看 T 和題目的語意靠得多近。選用可以下指令的編碼器,是為了讓比較的關係是「對回答這題有用的內容」,不只是字面相似。

報告值是所有 N 個輸出的算術平均,空 T 的 0 也算進去,所以 ETR 越高,平均 QRel. 越低。

自編例子(分數取自論文 Supplementary Table F.1):五個輸出的 QRel. 為 0(空)、0.896、0.310、0.831、0.276,平均 (0 + 0.896 + 0.310 + 0.831 + 0.276) / 5 ≈ 0.463。

限制:QRel. 量的是相關,不是推理;一句相關的事實陳述也可以得高分。論文把它定位為相關性訊號,不是推理的證據。

### 層 3:EIR(Explicit Inference Rate)

EIR 請一個 LLM 裁判逐筆判斷非空的 T 裡有沒有明確的推理步驟,用來分開「相關」與「推理」。

裁判是 GPT-5.5,只看到 (Q\_i, T\_i);模型名稱、介入模式、最終答案 A、答案對錯、QRel. 分數都被隱藏。它從五個標籤選一個,並摘出一段原文當證據;這段原文只供人檢查,不進指標。下表來自論文 Table 1,caption:"Blinded LLM-judge instruction and rubric for non-empty pre-answer text T."

| 編號 | 標籤 | 判準 | 算進 EIR |
| --- | --- | --- | --- |
| 1 | 泛用/離題 | 開場白、格式字、離題內容,沒有針對題目的推論 | 否 |
| 2 | 只改寫 | 重述題目或給定事實,沒有用推論連起來 | 否 |
| 3 | 相關但無推論 | 給出相關的事實、定義或答案斷言,沒有推論步驟 | 否 |
| 4 | 明確推理 | 有演繹、計算、比較、排除、套用規則、從證據到結論或因果,且針對題目 | 是 |
| 5 | 無法判定 | 光看可見文字無法可靠分類 | 否 |

只要有一個具體的推論步驟就算,即使很短、很淺、甚至最後算錯。

```latex
\mathrm{EIR} = 100\% \times \frac{1}{N}\sum_{i=1}^{N} \mathrm{Judge}(Q_i, T_i)
```

- Judge(Q\_i, T\_i):裁判選到「明確推理」為 1,選到其他四種為 0
- N:所有輸出的數量;空的 T\_i 不送裁判,直接算 0

白話:每個輸出各打 0 或 1,再取平均;EIR 是答案前有明確推理的輸出佔幾成,分母和 ETR、QRel. 一樣是所有輸出。

### 三層合起來看:六個回應案例

下表重製論文 Figure 3 的下半部(caption 同上),題目是 42 + 79 = ?,六個案例的最終答案都是 121,只有 T 不同。

| 案例 | T 的內容 | e\_i(ETR) | QRel. | 裁判標籤(EIR) |
| --- | --- | --- | --- | --- |
| 1 | 空 | 1 | 0 | 不送裁判,Judge = 0 |
| 2 | 短,寫出個位相加進位、十位相加 | 0 | 高 | 明確推理,Judge = 1 |
| 3 | 短,只寫 The answer is 121. | 0 | 低 | 泛用,Judge = 0 |
| 4 | 長,案例 2 的算式加上前後說明 | 0 | 高 | 明確推理,Judge = 1 |
| 5 | 長,泛談數學很重要 | 0 | 低 | 泛用,Judge = 0 |
| 6 | 長,說明加法是什麼,再說和是 121 | 0 | 中 | 相關但無推論,Judge = 0 |

- 長度與相關性互相獨立:案例 2、3 一樣短,但一個有算式、一個沒有;案例 4、5 一樣長,同樣一有一無。
- 相關不等於推理:案例 6 和題目有關,卻沒有推論步驟,要靠層 3 才分得出來。
- 自編例子:把六個案例當成六個輸出,ETR = 1/6 ≈ 16.7%,EIR = 2/6 ≈ 33.3%。兩者不互補,因為案例 3、5、6 的 T 非空,卻沒有推理。

### 六種介入模式

論文 Table 2,caption:"Six-mode question-irrelevant prompt intervention spectrum."

| 模式 | 名稱 | 思考開關 | 額外加的內容 | 壓制力道 |
| --- | --- | --- | --- | --- |
| M1 | THINK-ON | 開 | 無 | − |
| M2 | THINK-OFF | 關 | 無 | 0(基準線) |
| M3 | COT | 關 | "Think step by step." | − |
| M4 | SOFT | 關 | "A very short lead-in is allowed, but do not explain." | + |
| M5 | STRICT | 關 | "Give the final answer directly without any reasoning." | ++ |
| M6 | PREFIX | 關 | 預填答案範本 `The answer is \boxed{` | +++ |

六個模式的題目與「最終答案放進 `\boxed{}`」的要求都相同,只有思考開關與額外加的內容不同。M1、M3 是反方向的參照;M2 是原生關閉,作為基準線;M4 到 M5 用自然語言逐步加強限制;M6 不加指令,改為預填答案範本,論文因此把它視為獨立分支,不是更強的 STRICT。

## 3 實驗:關掉開關擋不住可見推理,題型越開放越明顯

只關掉思考開關時,答案前仍有明確推理的輸出比例隨題型越開放而升高(是非題 5.15%、選擇題 45.57%、開放式 99.69%);論文稱這個現象為 thinking inertia。

設定:六個模型(Qwen3-4B、Qwen3-32B、Qwen3-235B-A22B、DeepSeek-V4-Flash、GPT-5.4、Gemini-3-Flash)、三種答案空間各兩個 benchmark:是非(BoolQ、StrategyQA)、選擇(MMLU、MMLU-Pro)、開放式(GSM8K、MATH)。所有指標的分母都是全部輸出。

&#91;embedded content: 論文 Supplementary Table D.3 · 六個模型、六個 benchmark 合併 · M2 · GPT-5.5 為裁判\]

圖中數字來自 Supplementary Table D.3。原圖見論文 Figure 4,caption:"Think-on (M1), Think-off (M2), and Step-by-step (M3) across six models and three answer-space families."

- 加強指令只能部分壓制。在 M5 STRICT("Give the final answer directly without any reasoning.")下,三種題型的 EIR 都下降:是非 5.15% → 0.12%、選擇 45.57% → 25.39%、開放式 99.69% → 62.00%,但開放式仍有六成以上帶推理。
- 開放式要付準確度的代價。在思考可完全關閉的五個模型(不含 Gemini)上,從 M2 到 M5,開放式的 ETR 平均從接近 0 升到約 40%,準確度平均下降約 15 個百分點;是非與選擇題的準確度大致持平。論文稱這個取捨為 no-thinking–performance trade-off。EIR 取自六模型合併,ETR 與準確度取自五模型平均,基礎不同。
- 預填答案不是更強的 STRICT。從 M5 到 M6,選擇題與開放式的 ETR 平均下降(開放式回到接近 0),QRel. 與 EIR 在每種題型都回升。

論文的解讀(未直接驗證):開放式題目需要較多任務相關計算,所以較難只給答案。

## 【概念 1】T 與 A:怎麼從輸出切開

一句話版本:題目要求把最終答案放進 `\boxed{}`;最後一個可解析的答案是 A,它之前所有看得到的文字是 T,三層指標量的都是 T。

自編例子(T 取自 Figure 3 的案例 2,題目 42 + 79 = ?):

| 部分 | 內容 |
| --- | --- |
| 完整輸出 | `Ones: 2+9=11, carry 1. Tens: 4+7+1=12. \boxed{121}` |
| T | Ones: 2+9=11, carry 1. Tens: 4+7+1=12. |
| A | 121 |

```latex
\pi\big(S(Q)\big) = (T, A)
```

- Q:一個題目
- S(·):套在題目外面的介入(提示、輸出限制、思考開關等)
- π:被測的語言模型
- A:最後一個可解析的最終答案
- T:A 之前所有看得到的文字

白話:以最終答案為界,前面全部算 T,最後那個答案是 A。

- T 不限格式:文字出現在 `<think>` 區塊、一般回答區,或只有一句開場白,都算 T;有獨立推理欄位的 API,欄位內容也算進 T。
- A 之後若還有實質文字,ETR 視為不合格,因為嚴格檢查會掃整段輸出。
- T 在 A 之前是最常見的形式,不是硬性假設:在 535,208 筆含 `\boxed{}` 的輸出中,先給答案再解釋的只有 149 筆(約 0.028%,論文附錄 E),其後的解釋仍計入 T。
- (T, A) 只是對可見回應的拆法,不代表模型內部的運算。
