## 1. 基礎基石：KV 快取（KV Cache）與序列生成機制

要理解 KV Cache 壓縮技術的設計邏輯，必須先從大語言模型（LLM）在推論（Inference）階段的底層矩陣運算流動看起。

### 1.1 大語言模型的自迴歸推論流程

大語言模型在生成文本時，採用的是**自迴歸解碼（Autoregressive Decoding）**機制。這意味著模型是「逐字（Token by Token）」產生輸出的。

* **物理特徵與計算依賴：**
  當模型要預測第 $t+1$ 個 Token 時，它必須充分理解前面 $1$ 到 $t$ 個 Token 的語意與彼此之間的關聯。
* **無快取狀態下的效能災難：**
  在標準的 Self-Attention 機制中，如果在每一步生成時都不做任何狀態保留，為了計算第 $t+1$ 個字，系統必須把前 $t$ 個字重新輸入模型，重新進行線性投影（Linear Projection）與注意力矩陣相乘。這會導致運算複雜度隨著序列長度 $t$ 呈二次方 $O(t^2)$ 暴增，造成極大的算力浪費與延遲（Latency）。

### 1.2 KV Cache 的數學定義與 GPU 儲存流程

為了解決自迴歸推論中 $O(t^2)$ 的重複計算問題，工程界引入了 **KV Cache（鍵值快取）** 機制。其核心數學本質是**「用空間（GPU VRAM）換取時間（運算力）」**。

我們可以將每一次的生成步驟拆解為以下的數學與資料流動流程：

**1. 投影矩陣的運算退化：**
在第 $t$ 步時，模型的輸入僅為上一步剛生成的**單一 Token** 向量 $x_t \in \mathbb{R}^{1 \times d_{model}}$。我們只需對這一個向量進行線性投影：
* Query: $q_t = x_t W_Q \in \mathbb{R}^{1 \times d_k}$
* Key: $k_t = x_t W_K \in \mathbb{R}^{1 \times d_k}$
* Value: $v_t = x_t W_V \in \mathbb{R}^{1 \times d_v}$

**2. 拼接矩陣（Concatenation）與資料儲存流向：**
計算出當前的 $k_t$ 與 $v_t$ 後，系統不再丟棄它們，而是將它們**拼接到已經存在 GPU 記憶體中的歷史矩陣末端**。
* $\text{Cache}_K \leftarrow \text{concat}(\text{Cache}_K, k_t)$ （此時矩陣維度增長為 $t \times d_k$）
* $\text{Cache}_V \leftarrow \text{concat}(\text{Cache}_V, v_t)$ （此時矩陣維度增長為 $t \times d_v$）

**3. 注意力計算：**
利用當前單一的 $q_t$，與包含過去所有歷史的 $\text{Cache}_K$ 計算內積，隨後與 $\text{Cache}_V$ 加權求和：
$$a_t = \text{softmax}\left(\frac{q_t (\text{Cache}_K)^T}{\sqrt{d_k}}\right) \text{Cache}_V$$

> **💡 工程直覺（計算便簽）：**
> 模型權重矩陣（$W_K, W_V$）是靜態的，歷史 Token（$x_1 \dots x_{t-1}$）也是不可變的。因此，歷史 Token 投影出的 Key 和 Value 在每次運算中都完全相同。KV Cache 就是將這些「不變的運算結果」以矩陣形式長駐於記憶體中。這讓每一步的運算複雜度成功降階至 $O(t)$。

### 1.3 記憶體瓶頸與斷捨離：KV Cache Compression 的必要性

雖然 KV Cache 解決了算力瓶頸，卻引發了另一個嚴峻的硬體限制：**GPU 記憶體（VRAM）爆炸**。

* **長文本與思維鏈（CoT）帶來的災難：**
  在處理複雜數學題或代碼生成的任務時，模型會產生長達數萬個 Token 的推理鏈結（例如論文中提及的 AIME25 任務，生成長度可達 32K tokens）。此時，KV Cache 矩陣的列數 $t$ 會無止境地線性增長。
* **記憶體預算 $B$（Target Budget）與 OOM 危機：**
  硬體的 VRAM 是固定的。一旦 Cache 大小超過 VRAM 上限，系統就會觸發 Out-of-Memory (OOM) 錯誤並中斷服務。因此，在系統工程上，我們必須為 KV Cache 設定一個嚴格的**目標預算上限 $B$**（例如 $B = 2048$ 個 Token）。
* **KV Cache Compression（快取壓縮）的工程目標：**
  當生成長度 $t$ 超過預算 $B$ 時，系統必須啟動「斷捨離」機制。演算法必須掃描快取中的所有 Key，評估它們對**未來預測**的「重要性分數」，保留分數最高的前 $B$ 個 Key，並將其餘的特徵向量從矩陣中永久剔除。

## 2. 空間與位置：RoPE 位置編碼的幾何與數學

在 Transformer 架構中，特徵向量需要同時承載「語意（Semantics）」與「位置（Position）」兩種資訊。RoPE 提供了一種極具物理直覺的幾何解決方案。

### 2.1 為什麼需要位置編碼？

* **Self-Attention 的「排列無關性」硬傷：**
  標準的縮放點積注意力矩陣運算 $\text{softmax}(QK^T)V$，本質上是一種「詞袋模型（Bag-of-Words）」。它只計算向量間的內積相似度，完全無法感知 Token 在句子中的先後順序（例如無法區分「狗咬人」與「人咬狗」）。
* **絕對位置編碼的局限性：**
  早期的 Transformer 採用絕對位置編碼（將位置向量 $p_m$ 直接加到輸入特徵 $x_m$ 上）。此方法的致命傷在於**外推性（Extrapolation）極差**：如果模型訓練時只看過 512 長度的位置向量，在推論階段遇到第 1000 個位置時，會因為遇到未知的 $p_{1000}$ 而導致輸出崩潰。
* **相對位置編碼的需求：**
  人類語言高度依賴「相對距離」（如主詞與動詞相鄰），因此模型需要一種機制，讓 Query 和 Key 的內積結果**僅由它們之間的距離差決定**。

### 2.2 RoPE 的旋轉矩陣數學公式與推導

RoPE（Rotary Position Embedding）放棄了加法，改用**「旋轉（Rotation）」**將位置資訊注入到向量中。

**1. 運算對象的解耦：**
RoPE 並不作用在原始輸入 $x$ 或是提取語意內容的 Value ($v$) 上，而是專門作用於進行注意力配對的 Query ($q$) 和 Key ($k$) 上。這確保了純語意特徵（$v$）不會被位置旋轉干擾。

**2. 二維旋轉矩陣的數學定義：**
在基礎的二維空間中，假設有一個未旋轉前（Pre-RoPE）的向量 $q = \begin{pmatrix} q_1 \\ q_2 \end{pmatrix}$，當它處於序列的第 $m$ 個位置時，我們將其乘以一個旋轉角度為 $m\theta$ 的正交旋轉矩陣 $\mathbf{R}_{\theta, m}$：

$$ q'_m = \mathbf{R}_{\theta, m} q = \begin{pmatrix} \cos(m\theta) & -\sin(m\theta) \\ \sin(m\theta) & \cos(m\theta) \end{pmatrix} \begin{pmatrix} q_1 \\ q_2 \end{pmatrix} $$

> *[📝 筆記插入指示：可在此處對應論文中的 **Equation 1**，即論文中描述 $f$-th subspace 旋轉特性的數學公式。]*

### 2.3 核心證明：RoPE 內積如何實現「相對距離 $\Delta$」解耦

這是 RoPE 最優美的數學特質。我們來推導：一個位於位置 $m$ 的 Query ($q'_m$) 與一個位於位置 $n$ 的 Key ($k'_n$) 進行內積時，位置資訊是如何合併的。

**推導步驟：**
1. **內積的矩陣展開：**
   $$ \langle q'_m, k'_n \rangle = (q'_m)^T k'_n = (\mathbf{R}_{\theta, m} q)^T (\mathbf{R}_{\theta, n} k) $$
2. **轉置矩陣分配律：**
   利用 $(AB)^T = B^T A^T$，原式展開為：
   $$ q^T \mathbf{R}_{\theta, m}^T \mathbf{R}_{\theta, n} k $$
3. **旋轉矩陣的轉置與逆矩陣等價性：**
   $\mathbf{R}_{\theta, m}$ 代表順時針旋轉 $m\theta$ 度；其轉置矩陣 $\mathbf{R}_{\theta, m}^T$ 等同於逆矩陣，代表**逆時針旋轉 $m\theta$ 度**（即 $\mathbf{R}_{-\theta, m}$）。
4. **旋轉疊加：**
   先逆時針旋轉 $m\theta$，再順時針旋轉 $n\theta$，在幾何上等同於**淨順時針旋轉 $(n - m)\theta$ 度**：
   $$ \mathbf{R}_{\theta, m}^T \mathbf{R}_{\theta, n} = \mathbf{R}_{\theta, n-m} $$
5. **最終簡化結果：**
   $$ \langle q'_m, k'_n \rangle = q^T \mathbf{R}_{\theta, n-m} k $$

**💡 幾何與物理直覺：**
這個證明確立了一個核心結論：**不論這兩個 Token 處於文章的第幾頁，只要它們的相對距離 $\Delta = n - m$ 保持不變，它們內積時所經歷的空間旋轉角度就完全一致。** 這完美實現了距離解耦與外推能力。

### 2.4 多頻率設計（Multi-frequency）與外推性的關係

如果只使用單一頻率 $\theta$，當相對距離 $\Delta$ 足夠大，使得 $\Delta \cdot \theta = 2\pi$ 的整數倍時，旋轉矩陣會回到原點（週期性循環），導致模型無法分辨「距離很近」與「距離極遠但剛好差一圈」的 Token。

為了防範這個問題，大模型採用了**多頻率設計（Multi-frequency）**：

* **特徵空間的平面分割：**
  將一個高維度（例如 $d = 128$）的 Attention Head 向量，兩兩一組分割成 64 個獨立的 2D 空間。
* **幾何等比的頻率分配：**
  每一組 2D 空間 $i \in \{1, 2, \dots, 64\}$ 分配一個不同的基準旋轉頻率 $\theta_i$：
  $$ \theta_i = \theta_0^{-\frac{2(i-1)}{d}} $$
  （其中 $\theta_0$ 為基準常數，通常為 10,000 或更高）。
* **物理直覺（時鐘指針效應）：**
  * **高頻維度（前幾個平面）：** 旋轉極快，對位置變化極度敏感，負責精準捕捉局部（鄰近）的相對語法順序。
  * **低頻維度（後幾個平面）：** 旋轉極慢（數萬個 Token 才轉一小圈），負責建立全局上下文的長期記憶（Long-term memory）。

透過 64 種不同頻率的疊加干涉，高維向量在數百萬的序列長度內，幾乎不可能產生完全相同的週期性重合。

## 3. 傳統壓縮方法的硬傷：Post-RoPE 的「旋轉盲區」

在探討 TriAttention 的創新之前，必須先釐清為何現有的快取壓縮技術在處理長推論（如 Chain-of-Thought）時，會遭遇災難性的效能衰退。核心的癥結點在於：**傳統方法皆在「旋轉後（Post-RoPE）」的空間進行特徵觀測與淘汰決策。**

### 3.1 傳統方法的運算流程（以 H2O / SnapKV 為例）

傳統的 KV Cache 壓縮演算法，本質上是一種**「被動的動態觀測（Dynamic Observation）」**。它們不探究矩陣的幾何偏好，而是依賴歷史的注意力分數進行統計。其數學運算流程可拆解為四個步驟：

1. **獲取已旋轉特徵（Post-RoPE）：**
   在時間步 $t$，提取已經過 RoPE 旋轉的當前 Query 向量 $q'_t = \mathbf{R}_t q_t$，以及存在快取中已旋轉的歷史 Key 矩陣 $\text{Cache}_K = \big[ k'_1, \dots, k'_{t-1} \big]^T$。
2. **計算真實注意力權重（Softmax）：**
   計算當前 Query 對過去所有 Key 的真實注意力分數 $a_t$：
   $$a_{t,j} \propto \exp\left( \frac{q_t^T \mathbf{R}_{t-j} k_j}{\sqrt{d_k}} \right) \quad \text{其中 } j \in [1, t-1]$$
3. **分數累加（Score Accumulation）：**
   在記憶體中維護一個累加分數表 $S$。每前進一步，便將當前的注意力分數 $a_{t,j}$ 累加至對應的 Key 上（或只統計最近一個窗口長度的平均分數）：
   $$S[j] \leftarrow S[j] + a_{t,j}$$
4. **淘汰決策（Pruning / Eviction）：**
   當快取容量超出預算 $B$ 時，對分數表 $S$ 進行排序，將分數最低的 Token 及其對應的 KV 特徵從 GPU 記憶體中永久刪除。

### 3.2 旋轉矩陣 $\mathbf{R}$ 帶來的注意力震盪（Mathematical Instability）

傳統方法的數學破綻，就隱藏在步驟 2 的內積項 $q_t^T \mathbf{R}_{t-j} k_j$ 之中。

* **物理直覺：旋轉燈塔效應**
  想像當前的 Query 是一座「旋轉燈塔」，歷史的 Key 則是海面上的「礁石（關鍵資訊）」。因為矩陣 $\mathbf{R}_{t-j}$ 會隨著時間推移（$t$ 增大、相對距離變遠）而不斷改變旋轉角度，這導致燈塔的光束是不斷在海面上掃射的。
* **數學解構：波峰與波谷的震盪**
  內積運算底層由餘弦函數 $\cos(\omega_f \Delta + \phi_f)$ 構成。對於同一把已經存入快取的 Key（$k_j$ 是常數），當時間步從 $t$ 走到 $t+100$ 時，相對距離 $\Delta$ 改變，這會導致該 Key 所獲得的分數自然地產生**週期性的波峰與波谷**。

這意味著：一個分數極低的 Key，**未必是因為它的語意不重要，而可能純粹是因為位置旋轉將它暫時轉進了函數的「波谷（盲區）」**。

### 3.3 局部觀察窗口（Decoding Window）造成的致命誤殺

為了控制運算開銷與緩解歷史累加造成的偏差，傳統方法通常會設定一個**觀察窗口（Decoding Window，例如只看最近 32 步）**來評估 Key 的重要性。這種「短期統計」與「週期震盪」的疊加，引發了長文本推理中的致命誤殺。

1. **短期波動的幻覺：**
   如果某把關鍵的 Key 在這 32 步的觀察窗口內，剛好處於 RoPE 旋轉的「波谷」階段，模型在這段時間內賦予它的 $a_{t,j}$ 都會趨近於 0。
2. **不可逆的災難性淘汰（Catastrophic Eviction）：**
   傳統演算法會判定該 Key 無用並將其刪除。然而，當生成再往前推進 500 步時，旋轉角度本該將這把 Key 重新帶回「波峰」，讓它與未來的 Query 產生極大共振。但因為它在初期已被誤殺，未來的 Query 將永遠無法檢索到這段資訊。
3. **冬眠狀態（Dormant Keys）與推理鏈斷裂：**
   在進行數學推導或 DFS 回溯演算法時，許多核心條件會進入「冬眠狀態（長距離內暫不被關注，但最終結果依賴它）」。傳統方法無法識別這些處於冬眠期（波谷）的 Token，導致 Chain-of-Thought（CoT）推理鏈斷裂。

## 4. 關鍵物理發現：Pre-RoPE 空間的「Q/K 集中現象」

為了解決傳統方法在「旋轉燈塔（Post-RoPE）」下所產生的震盪與誤殺問題，TriAttention 的作者將觀測視角逆向推回到了**位置旋轉套用之前（Pre-RoPE 空間）**。在我們尚未將相對距離 $\Delta$ 耦合進去時，矩陣的原始幾何樣貌呈現了驚人的穩定性。

### 4.1 什麼是 Q/K Concentration（Q/K 集中現象）？

* **觀測對象的轉變：**
  我們不再觀察 $q'_t = \mathbf{R}_t q_t$，而是直接觀察通過線性投影後、尚未旋轉的原始特徵向量 $q_t$ 與 $k_j$。
* **物理現象的描述：**
  作者發現，對於任意一個特定的 Attention Head（專家），即使我們輸入了成千上萬個語意截然不同（如名詞、動詞、數字）的 Token，這些 Token 投影出來的 $q$ 和 $k$ 向量並不會在空間中漫天亂飛。相反地，它們有高達 80% 到 90% 以上的維度，會**死死地凝聚在一個固定的、非零的「中心點（均值向量）」周圍**。
* **幾何直覺（廣場上的指針）：**
  * **Post-RoPE（漫天亂飛）：** 像是一把被猛然打開的扇子，10,000 根指針因為被賦予了不同的旋轉角度，均勻且混亂地散佈在 360 度的圓盤上。
  * **Pre-RoPE（高度集中）：** 這 10,000 根指針幾乎完美疊加在一起，高度一致地指向特定的角度（例如「兩點鐘方向」）。這個現象即被稱為 **Q/K Concentration**。

> *[📝 筆記插入指示：請在此處插入論文的 **Figure 2(A)**。此圖以 2D 平面可視化了 Pre-RoPE 空間中，不同輸入序列的 Q/K 向量高度重合並凝聚於特定中心點的現象，與 Figure 2(B) 的散落弧形形成強烈對比。]*

### 4.2 量化指標：平均結果長度（Mean Resultant Length, $R$）

在嚴謹的科學工程中，不能僅靠肉眼觀測 2D 降維圖。為了精確量化這個「集中程度」，作者引入了方向統計學（Directional Statistics）中的經典指標：**$R$（Mean Resultant Length）**。

假設對於特定頻率 $f$，我們有一組 Query 向量分佈，其集中度 $R_f$ 定義為：
$$R_f = \frac{\|\mathbb{E}[q_f]\|}{\mathbb{E}[\|q_f\|]}$$

這個精妙的公式可以拆解為「分子」與「分母」的幾何張力對抗：
1. **分母 $\mathbb{E}[\|q_f\|]$（先取長度，再平均）：** 
   測量每個向量的絕對長度並計算平均值。它代表了這群向量在空間中的**「平均純量力量」**。
2. **分子 $\|\mathbb{E}[q_f]\|$（先算平均向量，再取長度）：** 
   將所有向量在幾何空間中進行**向量相加（Vector Addition）**，找到一個中心點向量，然後測量這根中心點向量的長度。

**💡 邊界情況與物理意義：**
* **完美集中（$R \to 1$）：** 當所有向量方向一致時，向量相加會產生完美的**相長干涉（Constructive Interference）**，長度完美疊加不抵消，此時分子等於分母，$R=1$。這代表該 Attention Head 具有極高的「方向共識」。
* **極度分散（$R \to 0$）：** 當向量指向四面八方時，向量相加會產生**相消干涉（Destructive Interference）**（例如向東的向量抵消了向西的向量），導致中心點向量長度趨近於 0，此時 $R=0$。

### 4.3 集中現象背後的物理本質與模型固有屬性

作者進一步對當代大模型（如 Qwen3-8B、Llama3 等）進行了大規模的 $R$ 值測量，得到了顛覆傳統認知的實驗數據：

1. **壓倒性的集中比例：**
   在 Qwen3-8B 中，有高達 **~90% 的 Attention Heads，其 $R$ 值大於 0.95**。這證明了 Q/K 集中現象不是特例，而是大語言模型的普遍法則。
2. **與輸入數據脫鉤（Domain Independence）：**
   實驗證明，不論輸入的是數學公式（Math）、程式碼（Code）還是日常對話（Chat），同一個 Attention Head 算出的 $R$ 值與中心點位置幾乎完全一致（數值極度穩定在 0.977 - 0.980 區間）。
3. **物理本質：專家的硬編碼特徵（Hardcoded Traits）：**
   這解釋了為什麼會有集中現象——每個 Attention Head 都是高度特異化的「專家」（例如專門尋找代名詞、或專門檢索遠距離名詞）。在其投影權重矩陣（$W_Q, W_K$）被訓練收斂後，該專家的「視角」與「幾何偏好」就已經作為**模型的物理固有屬性**被固定下來了。

## 5. TriAttention 核心理論：三角級數預測與雙軌評分

在確認了 Pre-RoPE 空間中 $q$ 與 $k$ 向量的高度集中性（$R \approx 1$）後，TriAttention 徹底放棄了傳統的「被動觀測（Dynamic Observation）」路線，轉而構建一套基於幾何先驗的「主動預測（Prior Prediction）」數學模型。

### 5.1 數學簡化：將 Q/K 變數替換為常數中心點

在標準的 RoPE 注意力內積公式中，分數是由三個變數共同決定的：目前的 Query ($q_t$)、歷史的 Key ($k_j$)，以及相對距離 ($\Delta = t - j$)。
因為 $q_t$ 和 $k_j$ 隨輸入文本不斷變化，傳統公式是一條無法預測的震盪曲線。

但在 Q/K Concentration 的前提下，既然特定 Attention Head 的向量高度凝聚，我們在數學上可以進行**大膽且誤差極小的期望值替換**：
* 將隨機變數 $q_t$ 替換為離線統計的均值常數 $\bar{q} = \mathbb{E}[q]$。
* 將隨機變數 $k_j$ 替換為離線統計的均值常數 $\bar{k} = \mathbb{E}[k]$。

替換後，原始的內積運算 $q_t^T \mathbf{R}_{\Delta} k_j$ 被近似為 $\bar{q}^T \mathbf{R}_{\Delta} \bar{k}$。
**在這個新的表達式中，$\bar{q}$ 與 $\bar{k}$ 皆為已知常數，唯一的未知變數只剩下相對距離 $\Delta$。**

### 5.2 三角級數公式（Trigonometric Series）的嚴謹數學推導

我們將上述的常數代入大模型中 64 組不同頻率（$f$）的 RoPE 二維平面進行展開。

對於任意距離 $\Delta$，其預期的注意力 Logit 可以寫成：
$$\text{logit}(\Delta) \approx \sum_{f} \Big( \|\bar{q}_f\| \|\bar{k}_f\| \cos(\omega_f \Delta + \bar{\phi}_f) \Big)$$

*   **振幅（Amplitude） $\|\bar{q}_f\| \|\bar{k}_f\|$：** 由 Q/K 的平均長度決定，為已知常數。
*   **相位差（Phase Difference） $\bar{\phi}_f$：** 兩中心點向量在未旋轉前的夾角，為已知常數。
*   **頻率（Frequency） $\omega_f$：** RoPE 內建的旋轉頻率，為已知常數。

透過三角函數展開，該公式等價於：
$$\text{logit}(\Delta) \approx \sum_{f} \big[ a_f \cos(\omega_f \Delta) + b_f \sin(\omega_f \Delta) \big]$$

**💡 數學本質與物理意義：**
這在數學上是一個標準的**三角級數（Trigonometric Series）**。這證明了：每個 Attention Head 其實都擁有自己專屬的**「注意力-距離關係曲線（Attention-vs-Distance Curve）」**。透過 64 個頻率的正餘弦波形干涉（類似傅立葉合成），模型天生就決定了它是偏好近處（局部頭）、偏好特定遠處（檢索頭）、還是對所有距離一視同仁（全局頭）。

### 5.3 評分軌道一：三角級數分數 ($S_{trig}$)

在推論（Inference）階段，我們需要決定快取中特定 Key ($k$) 的去留。
此時，我們擁有該 Key **真實的特徵向量 $k$**，但不知道未來 Query 會長什麼樣。因此，我們使用離線校準的 Query 中心點 $\mathbb{E}[q]$ 作為未來的「代理人」。

TriAttention 的第一個評分公式（距離偏好）定義如下：
$$S_{trig}(k, \Delta) = \sum_{f} \Big( \|\mathbb{E}[q_f]\| \cdot \|k_f\| \cdot \cos(\omega_f \Delta + \phi_f) \Big)$$
*(註：此時的相位差 $\phi_f = \text{arg}(\mathbb{E}[q_f]) - \text{arg}(k_f)$)*

*   **物理直覺（發射器與收音機共振）：** 
    這個公式在預測：基於這把 Key **真實的角度與強度（$\|k_f\|$）**，當未來的 Query 出現在距離 $\Delta$ 處時，RoPE 旋轉是否能剛好讓它們的頻率完美對齊（$\cos$ 接近 1，產生相長干涉）？如果預測會產生完美共振，該 Key 將獲得極高分數並被保留。

### 5.4 評分軌道二：語意模長分數 ($S_{norm}$)

**理論漏洞與工程補救：**
如果某個 Attention Head 的 Q/K 集中度較低（向量變異大），上述純靠角度共振的預測就會失準。此外，有些極度關鍵的實體 Token（如 System Prompt 或數學條件），其重要性純粹來自於其龐大的語意強度（向量 Norm 極大），而非特定的相對距離。

為此，作者設計了第二軌**完全無視距離（Distance-Independent）**的評分公式：
$$S^{(0)}_{norm}(k) = \sum_{f} \Big( \mathbb{E}[\|q_f\|] \cdot \|k_f\| \Big)$$

*   **物理直覺（大喇叭效應）：**
    該公式移除了 $\cos$ 旋轉項。它意味著：「不論未來距離多遠、角度有沒有對準，只要這把 Key 本身的語意力量 ($\|k_f\|$) 夠強大，且該頻率頻道是未來 Query 喜歡聽的 ($\mathbb{E}[\|q_f\|]$)，這把 Key 就具備絕對保留價值。」

### 5.5 基於集中度 $R_f$ 的自適應權重調節

TriAttention 面臨最後一個難題：如何將 $S_{trig}$（技巧共振分）與 $S_{norm}$（絕對力量分）合理融合？人為設定固定的超參數（Hyperparameter）顯然無法適應成千上萬個個性不同的 Attention Head。

作者巧妙地引入了在第四章計算的**集中度指標 $R_f$** 作為**自動調節開關（Mixer Slider）**：
$$S_{norm}(k) = \sum_{f} \Big( (1 - R_f) \cdot \mathbb{E}[\|q_f\|] \cdot \|k_f\| \Big)$$

*   **自動平衡機制（Auto-Balancing）：**
    *   **當方向極度集中（$R_f \to 1$）：** $(1 - R_f)$ 趨近於 0，$S_{norm}$ 被壓縮至極小值。系統表現出對 $S_{trig}$ 幾何距離預測的**絕對信任**。
    *   **當方向發生變異（$R_f$ 較低）：** $(1 - R_f)$ 權重放大，$S_{norm}$ 介入提供保底的「語意安全網（Safety Net）」，以彌補角度預測的潛在誤差。

**最終的綜合評分公式：**
$$S(k, \Delta) = S_{trig}(k, \Delta) + S_{norm}(k)$$

## 6. 走向實用：TriAttention 的工程落實與優化

在實際推論（Inference）階段，要將前述的雙軌打分公式 $S(k, \Delta)$ 實裝為高效的 CUDA/GPU 核心程式碼，必須克服「未知未來長度」、「逐字生成的頻繁開銷」以及「多頭共用快取」這三個系統工程障礙。

### 6.1 未來偏移量幾何等比採樣（Geometric Spacing）與波包干涉

在進行淘汰決策時，我們面臨一個邏輯悖論：公式需要代入一個相對距離 $\Delta$，但我們無法預知快取中的這把 Key 究竟會在未來的第幾步（是第 10 步還是第 10,000 步）被 Query 召回。

為了解決這個問題，作者不依賴單一時間點的預測，而是將評估視野擴展至整條時間軸，計算其**未來的平均期望分數**：
$$\tilde{S}(k) = \frac{1}{|\mathcal{D}|} \sum_{\delta \in \mathcal{D}} S(k, \Delta_0 + \delta)$$
（其中 $\Delta_0$ 為當下距離，$\delta$ 為未來偏移量）

**1. 工程優化：幾何等比採樣（Geometric Spacing）**
若對未來 65,536 步進行線性逐一計算（即 $\delta = 1, 2, 3 \dots$），巨大的 $O(N)$ 運算量將導致系統崩潰。作者採用了**幾何等比採樣**：
$$\mathcal{D} = \{1, 2, 4, 8, 16, \dots, 2^{16} = 65536\}$$
* **算力斷崖式下降：** 評估跨度長達 65,536 步，但實際計算次數僅需 **17 次**。
* **物理與 RoPE 的契合度：** 幾何採樣完美對應了 RoPE 多頻率的幾何特性。在近處，高頻維度旋轉劇烈、分數變化大，因此需要**密集採樣（Dense Sampling）**；在遠處，僅剩低頻維度緩慢變化，分數波動極小，因此可以**稀疏採樣（Sparse Sampling）**。

**2. 馴服 $\cos$ 震盪：波包干涉（Wave Packet Interference）**
這個求平均的積分設計，正是 TriAttention 不會重蹈傳統方法「週期性誤殺」覆轍的物理防線。
* 即使當下（$\delta = 0$）該 Key 處於餘弦函數的波谷（分數極低），只要它在未來的某個觀測點（如 $\delta = 2048$）會迎來波峰（高分），這個未來的共振分數就會在求平均時被捕捉並拉高整體評分 $\tilde{S}(k)$。
* 結合 64 個不同頻率的波形疊加，系統能看穿單一頻率的週期噪聲，捕捉到代表真實偏好的「波包包絡線（Envelope Curve）」。

### 6.2 窗口化剪枝（Window-based Pruning）的時間複雜度優化

在自迴歸推論中，若「每生成一個 Token」就觸發一次全域評分、排序與記憶體裁剪，會引發頻繁的 GPU 記憶體搬移（Memory Movement）與高延遲。

**分批處理（Batched Pruning）設計：**
* TriAttention 引入了區間觸發機制（設定 $\beta = 128$）。
* 系統平時允許 KV Cache 隨生成正常增長；只有當生成滿 128 個 Token（一個 Window）且總快取超過目標預算 $B$ 時，才會觸發一次全局打分與裁剪。
* **動靜分離的算力優化：** 在重新打分時，$S_{norm}$ 作為靜態語意特徵，無需重複計算；僅有 $S_{trig}$ 需要代入更新後的 $\Delta_0$（因為 Key 「變老了」，相對距離變遠），這使得在線運算開銷（Online Overhead）降至微乎其微。

### 6.3 GQA 多對一衝突的 Z-Score 標準化與 Max 彙整

當今最先進的大語言模型（如 Llama 3, Qwen）普遍採用 **Grouped-Query Attention (GQA)** 架構。在此架構下，為了節省 VRAM，$G$ 個獨立的 Query Heads 會共用同一個 Key-Value Head。
* **衝突來源：** 快取中的同一把 Key $k$，會被 $G$ 個具有不同中心點 $\mathbb{E}[q]$ 的專家同時打分，產生 $G$ 個不同尺度的分數。若直接加總，尺度大（Norm 較大）的 Head 會完全掩蓋尺度小的 Head 的決策。

為解決此工程衝突，TriAttention 設計了嚴謹的「Normalize-then-aggregate（先標準化後池化）」兩階段融合機制：

**步驟一：Z-Score 標準化（尺度對齊）**
對於每一個 Query Head $g$，利用其打出的所有分數計算均值 $\mu_g$ 與標準差 $\sigma_g$，強制將分數拉回標準常態分佈：
$$\hat{S}^{(g)}(k) = \frac{\tilde{S}^{(g)}(k) - \mu_g}{\sigma_g}$$
這消除了專家間的音量（Scale）差異，使分數具備跨 Head 的可比性。

**步驟二：最大值池化（Max Pooling）**
在完成尺度對齊後，採用 $\max$ 函數進行決策彙整：
$$S_{final}(k) = \max_{g \in \{0, \dots, G-1\}} \hat{S}^{(g)}(k)$$
* **物理直覺（一票否決，一票保存）：** 這是一個極度保守且安全的快取保護策略。在 $G$ 個共用該 Key 的專家裡，只要有**任何一個專家**認為這把 Key 在未來極度重要（最高分），系統就會將其保留。這避免了因為取平均值而犧牲掉少數特定專家（如檢索頭）的關鍵線索。

  在漫長的數學推導中，最初設立的方程式或條件變數，往往會在中間的數千步運算中進入**「冬眠狀態（Dormant State）」**（即暫時不被 Query 關注，處於 RoPE 的波谷）。

### 7.2 回溯能力的終極考驗：DFS 遞迴記憶體保留測試

這是本篇論文在檢驗「記憶體保留機制」上最嚴苛、也最具物理意義的實驗設計。作者構造了一個遞迴狀態查詢（Recursive State Query）基準測試，要求模型執行深度優先搜尋（DFS）的圖形走訪。

* **為什麼 DFS 是 KV Cache 的殘酷試金石？**
  DFS 演算法本質上依賴「堆疊（Stack）」與「回溯（Backtracking）」。當模型在第 20 層遞迴陷入死路時，它必須從記憶體中精準提取第 2 層遞迴時所留下的分支點狀態。任何中間節點（Intermediate State）的遺失，都會導致級聯錯誤（Cascading Errors），使最終結果完全崩潰。
* **實驗結果與臨界點坍塌：**
  * 在遞迴深度小於 16 時，TriAttention 的準確率曲線與 Full Attention 幾乎完全貼合，甚至在深度 8 與 12 時出現微幅領先（這暗示了 Full Attention 中可能存在干擾推理的冗餘噪聲，而 TriAttention 進行了有效過濾）。
  * 相比之下，R-KV 在深度達到 16 時發生了**災難性的性能坍塌（Catastrophic Degradation）**，準確率從深度 14 的 61% 直接墜落至 31%。
* **💡 深度洞察（回溯錨點的維護）：**
  這證明了 TriAttention 雙軌評分中的 $S_{norm}$（語意模長分數）與 $S_{trig}$ 的長距離預測，確實能在記憶體極度拮据的情況下，精準識別並死守那些作為「回溯錨點」的關鍵 Token，保證了演算法執行的邏輯閉環。

## 8. 技術對比與思考：兩代快取壓縮方法的範式轉移

在經歷了底層推導與實驗驗證後，我們可以用宏觀的技術視角，來重新審視這項技術所帶來的系統架構啟發。TriAttention 的出現，不僅僅是一個演算法的迭代，更是快取壓縮領域中從「動態觀測」到「先驗預測」的一次**範式轉移（Paradigm Shift）**。

### 8.1 傳統「觀測派」與 TriAttention「預測派」的數學本質對比

兩代方法代表了兩種截然不同的系統設計哲學：

*   **傳統觀測派（經驗主義 Empiricism）：**
    *   **運作邏輯：** 如同做「即時民意調查」。在每次解碼時，去觀測並統計「當前的 Query 投給了哪些歷史 Key 最高的分數」。
    *   **系統硬傷：** 它極度依賴於短期的觀察窗口。由於 RoPE 的旋轉機制，分數呈現動態震盪，這使得「過去的高分無法保證未來，過去的低分也未必代表無用」。這種滯後且短視的經驗主義，注定會在長文本的「冬眠 Token」上栽跟頭。
*   **TriAttention 預測派（理性主義 Rationalism）：**
    *   **運作邏輯：** 基於第一性原理（First Principles）。在 Key 誕生的那一刻（寫入快取時），直接利用其真實的特徵向量與離線算好的 Q 中心點，在數學上「預畫」出它未來完整的命運曲線。
    *   **系統優勢：** 由於解除了對「即時動態」的依賴，模型從一開始就能以「上帝視角」精準掌握每一把 Key 在未來 6.5 萬步內的潛在價值，徹底消除了短期觀察造成的盲區。

### 8.2 為什麼同為 Cosine 函數，TriAttention 不會產生週期性誤殺？

這是一個極其刁鑽且直指核心的數學問題：既然注意力運算底層都是 $\cos$，為什麼 TriAttention 不會像傳統方法一樣，在「波谷」時產生誤殺？

這歸功於觀測視角與頻率處理上的物理差異：
1.  **從「孤立點觀測」到「波形數值積分」：**
    傳統方法只觀測當下時間步 $t$ 的分數（即餘弦曲線上的一個孤立點）。若該點剛好處於波谷，即被判定無用。而 TriAttention 透過**幾何等比採樣 $\mathcal{D}$**，對未來的 17 個關鍵距離進行了平均計算。這相當於對未來波形進行了**數值積分**，即使當下處於低谷，未來的波峰共振也會在積分過程中被捕捉並拉高平均分。
2.  **多頻率「波包干涉（Wave Packet Interference）」：**
    傳統方法在 Post-RoPE 空間拿到的是 64 個頻率混雜並經過 Softmax 壓縮的單一黑盒子數值，無法分辨噪聲與信號。TriAttention 在 Pre-RoPE 空間將 64 個頻率分開計算，這使得不同頻率的波形能產生物理上的干涉。最終合成的曲線不再是無盡的震盪，而是具有明確指向性與衰減特性的「波包（Envelope Curve）」，極大地提升了數學評估的穩定性。

### 8.3 自適應動靜分離設計在 GPU 計算優化上的啟發

從演算法工程師的角度來看，這篇論文在處理 $S_{trig}$ 與 $S_{norm}$ 雙軌評分時的「動靜分離」設計，是極具參考價值的架構巧思。

*   **靜態屬性（$S_{norm}$ 語意模長分）：** 
    這是 Key 的「本質屬性」。在 Key 寫入快取時，其長度與常數的乘積即固定。在 GPU 實作上，這部分可以**只計算一次並快取起來（Cached Calculation）**，後續完全不佔用算力。
*   **動態屬性（$S_{trig}$ 距離共振分）：**
    這是 Key 的「時效性屬性」。隨著新 Token 不斷生成，Key 與最新 Query 的相對距離 $\Delta$ 逐漸變遠，導致 $\cos$ 相位偏轉。因此這部分必須重新計算以反映最新價值。
*   **工程啟發：** 
    透過將不變的常數項抽離，並結合批次處理（每生成 128 步才觸發一次重算），TriAttention 成功將極度複雜的高維注意力矩陣運算，降維成只需更新純量距離 $\Delta$ 的輕量級運算，完美兼顧了理論深度與硬體執行效率。

## 結論

《TriAttention: Efficient Long Reasoning with Trigonometric KV Compression》一文，針對大型語言模型在長文本與長鏈條推理中面臨的 KV Cache 記憶體瓶頸，提出了一套兼具數學美感與工程實用性的解決方案。

本筆記客觀梳理了該技術的核心脈絡：
1.  **破除旋轉盲區：** 揭示了 Post-RoPE 空間中因位置旋轉造成的動態震盪，是導致傳統壓縮方法誤殺冬眠 Token、切斷推理鏈的根本原因。
2.  **發現物理特徵：** 透過方向統計學指標 $R$ 的驗證，確立了 Pre-RoPE 空間中 Q/K 向量高度集中的模型固有幾何屬性。
3.  **推導預測級數：** 將隨機變數替換為常數中心點，嚴謹推導出純粹依賴相對距離的三角級數預測公式（$S_{trig}$），並搭配語意模長分數（$S_{norm}$）與 $(1-R_f)$ 自適應權重，構築了無超參數的雙軌評分系統。
4.  **跨越工程障礙：** 引入未來偏移量的幾何等比採樣、區間批次裁剪，以及應對 GQA 架構的 Z-score Max-pooling 機制，實現了 GPU 上的極致效能。

**最終的系統工程啟發：**
在 AI 系統底層優化的道路上，「遇水搭橋」的修補（如單純拉長觀察窗口）往往會陷入局部最佳解。TriAttention 展現了另一種境界：**回到模型架構的第一性原理，尋找其數學與物理上的本質規律（如幾何集中特性），並依此設計預測模型。** 這種從本質出發的系統設計思維，比演算法本身的跑分更值得所有 AI 軟體工程師學習與借鑑。
